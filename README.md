# Webrya: Your Smart Host Hub

You are a senior product designer, UX strategist and full-stack web developer.

We are building the official website and initial MVP of a new product called:

WEBRYA

Domain:

https://webrya.com

IMPORTANT:

This is NOT a generic SaaS startup.

Do NOT build the website around monthly SaaS subscriptions.

Webrya is a digital platform and product ecosystem for Airbnb hosts and short-term rental professionals.

The business model combines:

1. Free AI tools

2. One-time digital products

3. Premium Webrya packages

4. A Webrya Host Portal

5. Higher-tier solutions for professional hosts, co-hosts and property managers

The website must feel like a real commercial product/company, not a template, agency website or generic AI SaaS dashboard.

==================================================

BRAND POSITIONING

==================================================

Webrya helps Airbnb hosts operate their short-term rental business more efficiently using AI-powered tools, ready-made resources and professional digital solutions.

Core positioning:

"Everything you need to run your short-term rental smarter."

Alternative supporting message:

"AI tools, resources and digital solutions built for short-term rental hosts."

The target audience is international.

Primary language:

English.

Target customers:

- Airbnb hosts

- Short-term rental hosts

- Co-hosts

- Property managers

- Small property management businesses

Do NOT position Webrya as an Airbnb management company.

Do NOT make cleaning, co-hosting or traditional website development the core service.

Webrya is a PRODUCT COMPANY.
